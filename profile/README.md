Official GitHub presence for Wolkenfuchs Entertainment with a broad range of Wolkenfuchs-maintained developer tools & technologies. Here you'll find two main types of repositories:

- **Projects' Stuff & other licensed source repositories**, that require becoming a member to accept the EULA.
- **Open source repositories**, which are publicly accessible under various open source licenses.

If a repository's status is unclear, please treat it as EULA-gated and contact us before use.

---

# Licensed Source Repositories

To access our licensed source repositories, please consider linking you account to Wolkenfuchs on GitHub.

Please note:

- You must be signed into GitHub and registered for access for these links to work. Once you have access, these repositories are clearly labeled with the topics `wolkenfuchs-eula`.
- Contributions to licensed our Project source repositories remain subject to the applicable Wolkenfuchs license agreements.

---

# Open Source Repositories

Open source repositories in this organization are clearly labeled with the `open-source` topic and are licensed under their respective open source licenses (MIT, Apache 2.0, etc.)

These repositories **do not require** EULA acceptance, or membership in the `Wolkenfucs` GitHub organization.

**We do not welcome contributions to our open source repositories right now.**
